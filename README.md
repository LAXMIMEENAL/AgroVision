# AgroVision

## GeoAI Smart Agricultural Intelligence Platform

AgroVision is a machine learning and geospatial intelligence project designed to provide data-driven insights for agricultural monitoring.

The project combines vegetation analysis, weather information, machine learning, and an interactive dashboard to study agricultural conditions and generate a risk score.

## Problem Statement

Agricultural conditions are influenced by multiple environmental factors. Analysing vegetation health together with weather information can provide useful insights for monitoring agricultural conditions.

AgroVision explores how geospatial and environmental information can be combined with machine learning to support agricultural intelligence.

## Approach

The project follows a data-driven pipeline:

Environmental Data
→ Data Processing
→ NDVI Analysis
→ Feature Engineering
→ Machine Learning
→ Risk Score
→ Dashboard

## Key Components

### NDVI Analysis

NDVI (Normalized Difference Vegetation Index) is used as a vegetation-related feature for analysing agricultural conditions.

### Weather Integration

Weather information is incorporated as an environmental factor in the analysis.

### Machine Learning

A Random Forest Regressor is used as part of the prediction pipeline.

### Risk Scoring

The project includes a risk score computation based on the processed agricultural and environmental information.

### Interactive Dashboard

The results are presented through an interactive dashboard for easier exploration and interpretation.
